## A. 旧誌（日本釀造協會雜誌）の取り込み可否

### 所在・規模
- `32.研究事業/日本釀造協會雜誌/` 配下。**巻10〜26のみ実体あり（2,162 PDF）、巻27〜82は空フォルダ**（前任の発見どおり。全75巻フォルダのうち中身があるのは17巻分のみ実測確認）。
- 各巻フォルダ配下に `N号`（1〜12号、毎巻12号で欠番なし）→ `{巻}_{開始頁}[a|b|c].pdf` の1論文1PDF構成。書誌CSV・台帳の類は一切無い（`find` で巻フォルダ直下・BASE直下ともに非PDFファイル0件）。
- ファイル名の数字＝印刷頁の開始頁と一致することを実測で確認（例: `13_26.pdf` の本文冒頭に頁番号「二六」＝26が出現）。同一頁に複数論文がある場合のみ `a/b/c` 接尾辞（実測5件）。

### 可読性（無作為30本、`pdftotext -raw` → 自炊本と同じ空白畳み込み正規化）
| 観点 | 結果 |
|---|---|
| スキャン種別 | 画像スキャンのOCR済みテキスト（縦書き・旧字体・歴史的仮名遣い） |
| `-raw`のまま | 文字間に空白が入り読みにくい（例:「醸 造 脇 書 誰 誌」） |
| 既存 `normalize_page()`適用後 | 空白が畳まれ**十分可読**（人が読める古文的日本語。技師名・論文題・専門用語が判別可能） |
| OCR誤字 | 見出し部分で散発（「醸造脇書誰誌」など）。本文は概ね安定。誤字率は自炊本5冊より高いが検索の障害になるほどではない |
| 30本中の失敗 | 0本（`too_short`等の除外なし） |

### 頁つき出典
- **可能**。巻＝フォルダ名、号＝フォルダ名、開始頁＝ファイル名の数字、終了頁＝開始頁＋PDF物理頁数−1（`ingest_papers.py` と同じ「頁数一致で確定」方式がそのまま使える）。
- **発行年は台帳に無い**。ただし原文中に年号の自己言及が3件見つかり、相互に整合する一次資料内在的な仮説が立つ：
  - 10巻9号の本文が「醸造〇〇雑誌**第十年**第九號」と自称（＝この雑誌の10年目）
  - 19巻4号に「大正一三・三・一五稿」（＝大正13年=1924年）
  - 22巻5号に「昭和二年三月三日…講演の大要」（＝昭和2年=1927年）
  - いずれも **年 = 巻 + 1905**（創刊を1906年＝明治39年と仮定）で一致。ウェブ検索はしていないので「有力仮説・要検証（あと数本の巻で裏取りしてから台帳に書く）」に留める。捏造回避のため sources.csv には書き込んでいない。

### パイロット取り込み（別DB、本番非接触）
- `data/pilot_kyushi.sqlite` に無作為50本を投入（`kbdb.py`のスキーマ・`extract_books.py`の正規化関数をそのまま再利用、投入スクリプトは session scratchpad）。50/50成功、367チャンク。
- 検索確認（`kb.search(..., db="data/pilot_kyushi.sqlite")`）: 「麹」「酒母」「酵母」「清酒 分析」の4クエリで的中、頁付き引用が返る（例: `日本釀造協會雜誌（旧誌） 20巻11号 pp.20-24 p.20（年:要確認）`）。「醤油 発酵」はAND一致なしで0件（サンプル数50本のため）。
- 既存 `kb.py` の `cite()` は年欠落を「書誌未登録」表示にフォールバックする作りなので、年を仮置きするまでは巻・号・頁は出せても年だけ「要確認」と手当てする軽微な分岐が要る（あるいは年を仮説値のまま`要確認`フラグ付きで docs.year に文字列格納する運用）。

### 全量取り込みの所要見積り
- 2,162本、単純計算で jbsj（4,278本・8並列13分）の約半分 → **8並列で7〜8分程度**（pdftotextコスト同等と仮定）。ボトルネックはコード側でなく年号仮説の検証（数本を人が目視で追加照合）。
- 手順は jbsj と同型：①巻年対応を数巻追加検証→sources.csv に1行（type=学会誌、tier=T1、note に「年=巻+1905（要検証）」等） →②専用ingestスクリプト（ファイル名パースを追加した ingest_papers.py 相当）→③検証係が頁対応を独立検証。
