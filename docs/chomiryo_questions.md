# 調味料の味の分布 — 問いの定義（2026-09-08 仮置き・オーナー修正可）

目的: 47県発酵文化データ層に「醤油・味噌の地域差」を足すため、何を知りたいかを先に固定する。
問いに無いことは抽出しない（足さない）。酢・みりん・塩・魚醤は件数だけ出し、問いは立てない。

## 醤油（5問）
1. 県の主流タイプはどれか（濃口／淡口／たまり／白／再仕込）。
2. 「甘口」が主流とされる県はどこか（九州・北陸・山陰の言及を確認）。
3. たまり・白醤油の産地はどこか（東海に偏るか）。
4. 淡口の産地はどこか（兵庫・関西に偏るか）。
5. 魚醤が伝統的に使われる県はどこか（秋田・石川・香川など）。

## 味噌（5問）
6. 県の主流原料はどれか（米味噌／麦味噌／豆味噌）。
7. 色の傾向はどれか（赤／白／淡色）。
8. 甘口／辛口の傾向はどれか。
9. 豆味噌の産地はどこか（愛知・三重・岐阜に閉じるか）。
10. 麦味噌の産地はどこか（九州・四国・中国西部に閉じるか）。
